quantms

DDA pipeline · release 1.10.0

Label-free and TMT/iTRAQ quantification with Comet, MS-GF+ or Sage, Percolator rescoring and OpenMS quantification.

Documentation · GitHub

quantmsdiann

DIA pipeline · release 2.3.0

Data-independent acquisition with DIA-NN, library-free or with a spectral library, from one SDRF file.

Documentation · GitHub

Run it

Both pipelines take an SDRF file describing samples, raw files and labels, and run with Docker or Singularity on a laptop, an HPC cluster or a cloud account.
